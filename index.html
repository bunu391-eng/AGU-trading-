Supported flow

TradingView alerts can send an HTTP POST webhook to the secure backend. The backend validates and stores the signal; this dashboard then displays it. TradingView recommends secure HTTPS webhook endpoints and warns against sending credentials in webhook messages.

Webhook payload format

{
  "provider": "TradingView",
  "symbol": "EUR/USD",
  "direction": "BUY",
  "entry": 1.08420,
  "stop_loss": 1.08020,
  "take_profit": 1.09220,
  "timeframe": "1H",
  "message": "EMA + MACD setup"
}

Do not put passwords, broker credentials or private keys in webhook messages.
